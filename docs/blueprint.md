# **App Name**: Academia Authenticity Verifier

## Core Features:

- Homepage Gateway: Clear entry points for public verification and institutional login.
- Certificate Verification Form: Form to upload credentials and document file
- Simulated Verification: Simulate a backend API call. Use an LLM to simulate reasons why uploaded certificate/document combo can be flagged as a potential tool.
- Institutional Login: Login form for institutional access.
- Cross-Navigation: Links or buttons for easy navigation between pages.

## Style Guidelines:

- Primary color: Soft blue (#74A4BC) for trust and clarity.
- Background color: Very light blue (#F0F4F7), close to white.
- Accent color: Muted purple (#8B79A7) for interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) for readability and a modern feel.
- Use professional, clear icons related to verification and institutions.
- Clean, grid-based layout with clear sections and cards.
- Subtle animations for loading states and result transitions.
